# Albite

**A dependently typed language for formal proofs and systems programming.**

Albite brings together Rust-inspired syntax, Lean-inspired formal reasoning and native compilation through LLVM. Its goal is to make precise specifications, checked proofs and practical software work together in one language.

Previously known as **Tungsten**, Albite is under active development. See the [main repository](https://github.com/albite-lang/albite) for current capabilities, installation instructions and known limitations.
